# Ponsia Perps

Perps for every PONS token. Long the runners, short the rugs. Built on Robinhood Chain.

- `/` is the website.
- `/app` is the trading dashboard (loaded on demand, so the website never downloads the wallet stack).

## Run it

```bash
npm install
cp .env.example .env   # then fill in VITE_REOWN_PROJECT_ID
npm run dev
```

| Variable | Required | What it does |
|---|---|---|
| `VITE_REOWN_PROJECT_ID` | for wallets | Reown AppKit project ID ([dashboard.reown.com](https://dashboard.reown.com)). Without it the app still shows markets and listings, and explains how to enable wallets. |
| `VITE_ROBINHOOD_RPC_URL` | no | A dedicated Robinhood Chain RPC (for example Alchemy). Defaults to the public, rate-limited RPC. |
| `VITE_PONSIA_PERPS_ADDRESS` | for trading | The Ponsia Perps engine contract. Leave empty until it is deployed. |

## Deploy on Vercel

`vercel.json` is ready: Vite build to `dist`, SPA rewrites (so `/app/...` routes load directly), long-cache
headers for hashed assets, basic security headers, and a `www.ponsia.xyz` to `ponsia.xyz` redirect.

1. Import `Trixen-AI/pontis` in Vercel. Framework, build command and output are picked up from `vercel.json`.
2. Add the environment variables (Project Settings, Environment Variables, for Production and Preview):

   | Name | Value | Required |
   |---|---|---|
   | `VITE_REOWN_PROJECT_ID` | your Reown project ID | yes |
   | `VITE_ROBINHOOD_RPC_URL` | a dedicated RPC, e.g. `https://robinhood-mainnet.g.alchemy.com/v2/<key>` | recommended |
   | `VITE_PONSIA_PERPS_ADDRESS` | engine contract address | only once the engine is live |

   `VITE_` variables are baked in at build time and are public in the browser bundle. Never put a private key or
   secret here. Redeploy after changing them.
3. Domains: add `ponsia.xyz` and `www.ponsia.xyz` to the project and set the DNS records Vercel shows.
4. In the Reown dashboard, add `ponsia.xyz` (and your `*.vercel.app` preview domain if you test there) to the
   project's allowed domains, or the wallet modal will refuse to connect in production.

## SEO

`index.html` carries the title, description, canonical, Open Graph and X card tags, icons, the web manifest and
JSON-LD. `useSeo()` (`src/lib/seo.ts`) updates title, description and canonical per route; Positions and Portfolio
are `noindex`. `public/robots.txt` and `public/sitemap.xml` point at `https://ponsia.xyz`. The share image and
app icons are generated by `npm run brand`.

## Dashboard

| Page | What it shows | Data source |
|---|---|---|
| Markets | Every PONS token with a live price: Runners, Rugs, Most traded, New on curve. Paste any address to open its market. | GeckoTerminal (Pons curve, Pons graduated, Pons V1 pools) |
| Market | Candles, live mark price, pool stats, holders, spot trades, the order ticket, and your spot balance with a one-click hedge. | GeckoTerminal, DexScreener, Blockscout, on-chain reads |
| Listings | Live feed of Pons launches and graduations, straight from the factory logs, polled every 5 s. | Robinhood Chain RPC |
| Positions | Your open perps, marked to the live price, with close and add-margin, plus recent history. | Ponsia Perps engine contract |
| Portfolio | ETH margin, the PONS tokens the wallet holds (checked on-chain against the Pons factories), hedge shortcuts, recent activity. | Blockscout, DexScreener, on-chain reads |

A token counts as a PONS token only if the Pons factories say so on-chain:
`PonsV2LaunchFactory.getLaunchedToken(token).exists` (V2) or a `TokenLaunched` log from the legacy V1 factory.
Addresses live in `src/app/config.ts`.

### Leverage caps (until the engine sets its own)

| Market | Max |
|---|---|
| Graduated, pool depth from $250k | 10x |
| from $50k | 5x |
| from $10k | 3x |
| Still on its bonding curve, from $25k 24h volume | 2x |
| Anything thinner | view only |

## Perps engine interface

The engine is not deployed yet. The dashboard already talks to it through the interface in
`src/app/lib/perps/abi.ts`: `openPosition`, `closePosition`, `addCollateral`, `positionsOf`,
`liquidationPrice`, `maxLeverage`, `maintenanceMarginBps`, `tradingFeeBps`, `isMarketListed`, and the
`PositionOpened` / `PositionClosed` / `PositionLiquidated` events. Collateral is ETH sent as `msg.value`;
prices are USD with 18 decimals. Deploy a contract that implements it, set `VITE_PONSIA_PERPS_ADDRESS`,
and order submission, positions and history turn on with no other change.
